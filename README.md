# Customer Profitability & Discount Impact Analysis

## Project Overview
This project analyzes customer-level profitability and the impact of discount strategies on revenue and profit.

## Tools & Technologies
- SQL (SQLite)
- Python (Pandas, NumPy, Matplotlib)
- Power BI
- Excel

## Key Insights
- High discounts significantly reduce profit margins
- High-revenue customers are not always profitable
- Customer segments respond differently to discounting

## Dashboard
Power BI dashboard visualizes:
- Customer profitability
- Discount impact on profit
- Segment-wise profit distribution
